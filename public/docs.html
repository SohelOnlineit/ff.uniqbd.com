1. Quick Start Overview

Connect your top-up website to AroraShop Auto-Delivery API in 3 simple steps:

  1. Get Credentials: Log in to your Partner Dashboard at https://ff.uniqbd.com/user/login → open API Keys, Webhook & Telegram to copy your X-API-Key and X-API-Secret.
  2. Top-Up Wallet (BDT): Top up your BDT wallet instantly from your dashboard via bKash / Nagad / Rocket / Upay (pay.arorashop.com) and check your custom BDT diamond price list.
  3. Send Order + Receive Webhook: When a customer pays on your website, call POST /api/reseller/v1/order. Our engine delivers the diamonds automatically and sends a signed POST callback to your Webhook URL so your website marks the order COMPLETED automatically!
Base URL: https://ff.uniqbd.com  •  All requests and responses use application/json over HTTPS.

2. Authentication Headers

Include these two headers in every backend API request (never expose your X-API-Secret in frontend browser JavaScript):

Content-Type: application/json
Accept: application/json
X-API-Key: arora_live_your_api_key_here
X-API-Secret: arora_sec_your_api_secret_here

4. Place a Top-Up Order

POST https://ff.uniqbd.com/api/reseller/v1/order

Call this immediately after your customer completes payment on your website. order_id is idempotent — sending the same order_id twice will never double-deliver or double-charge.

Request Body (JSON)

{
  "order_id": "ORD-10045",
  "player_uid": "1234567890",
  "package_code": "FF_25D",
  "quantity": 1
}

Success Response (HTTP 200)

{
  "ok": true,
  "order_id": "ORD-10045",
  "order_utr": "RES1-ORD-10045",
  "player_uid": "1234567890",
  "package_code": "FF_25D",
  "package_name": "25 Diamond",
  "quantity": 1,
  "order_price_bdt": 30,
  "status": "QUEUED_EXT",

6. How to Build & Connect Your Webhook (Auto-Complete Orders)

A Webhook is a public POST URL on your website (for example: https://yourwebsite.com/api/arora-webhook). As soon as AroraShop finishes delivering diamonds to the player's UID, our server sends an HTTP POST request to your Webhook URL so your website marks the order COMPLETED automatically — zero manual work!

Step-by-Step Setup:

  1. Create a POST endpoint on your website using one of the code templates below (disable CSRF protection on that webhook route!).
  2. Verify the X-Arora-Signature header using HMAC-SHA256 with your X-API-Secret so nobody can forge fake completion callbacks.
  3. When status === "COMPLETED", find order_id in your database and mark it Completed / Delivered.
  4. Return HTTP 200 OK with {"ok": true}.
  5. Go to Partner Dashboard → API Keys, Webhook & Telegram → paste your Webhook URL → click Save Webhook URL → click Send Test Webhook to confirm HTTP 200 OK!

Webhook Headers Sent by AroraShop

Content-Type: application/json
X-Arora-Event: order.completed
X-Arora-Timestamp: 1763720400
X-Arora-Signature: <hmac_sha256(timestamp + "." + rawJsonBody, your_api_secret)>

Webhook JSON Payload

{
  "event": "order.completed",
  "order_id": "ORD-10045",
  "internal_ref": "RES1-ORD-10045",
  "status": "COMPLETED",
  "player_uid": "1234567890",
  "package_code": "FF_25D",
  "package_name": "25 Diamond",
  "diamonds": 25,
  "quantity": 1,
  "method_used": "loaded_account",
  "price_deducted_bdt": 30,

Important Security Rule: Always verify X-Arora-Signature before marking any order as Completed! Compute HMAC-SHA256(X-Arora-Timestamp + "." + rawBody, your_api_secret) and compare using constant-time comparison (hash_equals / crypto.timingSafeEqual).

7. Ready-to-Use Webhook Handler Code

// 1) In routes/api.php (no CSRF needed for api routes):
Route::post('/arora-webhook', [AroraWebhookController::class, 'handle']);

// 2) In app/Http/Controllers/AroraWebhookController.php:
<?php
namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\Order;

class AroraWebhookController extends Controller
{
    public function handle(Request $request)
    {
        $secret    = env('ARORA_API_SECRET');
        $rawBody   = $request->getContent();
        $timestamp = $request->header('X-Arora-Timestamp', '');
        $signature = $request->header('X-Arora-Signature', '');

        // Verify HMAC-SHA256 Signature
        $expected = hash_hmac('sha256', $timestamp . '.' . $rawBody, $secret);
        if (!$signature || !hash_equals($expected, $signature)) {
            return response()->json(['ok' => false, 'error' => 'Invalid signature'], 401);
        }

        $data = $request->json()->all();
        if (!empty($data['test'])) {
            return response()->json(['ok' => true, 'message' => 'Test webhook received!']);
        }

        $order = Order::where('id', $data['order_id'] ?? null)->first();
        if ($order && ($data['status'] ?? '') === 'COMPLETED') {
            $order->update([
                'status' => 'completed',
                'delivery_note' => $data['receipt_note'] ?? 'Auto-delivered',
            ]);
        }

        return response()->json(['ok' => true]);
    }
}
